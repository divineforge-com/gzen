## 2025-02-22 - Keyboard Shortcut Tooltips Accessibility
**Learning:** Adding visual tooltip (title attribute) that mentions keyboard shortcut along with `aria-keyshortcuts` creates better discoverability for sighted users who might not read the text hint or for those who don't use screen readers but prefer keyboard navigation.
**Action:** Always include keyboard shortcut information in `title` (or custom tooltip) when implementing `aria-keyshortcuts` to benefit a wider range of users.
