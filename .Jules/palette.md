## 2024-05-18 - Discoverable Keyboard Shortcuts for Interactive Cards
**Learning:** The Astro portal implements global keyboard shortcuts (Z, E, N) to focus and trigger interactive Element Cards. While the functionality is robust, the cards lacked semantic indicators for assistive technologies to identify these shortcuts. Adding `aria-keyshortcuts` allows screen readers to announce the shortcut natively, and appending the shortcut to the `title` attribute provides a non-intrusive tooltip for sighted users, significantly improving discoverability without cluttering the UI.
**Action:** For all custom UI components with specific keyboard shortcuts, explicitly define the `aria-keyshortcuts` attribute mapping to the keystroke, and consider adding the shortcut in parentheses to the native tooltip via the `title` attribute for broader discoverability.
