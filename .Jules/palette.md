## 2024-05-18 - Keyboard Shortcut Discoverability
**Learning:** Hidden global keyboard shortcuts are frequently missed by users and screen readers unless explicitly documented in the UI.
**Action:** Surface global keyboard shortcuts (like Theme toggle or Path navigation) on interactive elements using `aria-keyshortcuts` for assistive technologies and parenthetical tooltip hints (e.g., `(Shortcut: T)`) in the `title` attribute for sighted users.
