## 2024-05-24 - Accessibility attributes for custom keyboard shortcuts
**Learning:** The application implements custom keyboard shortcuts for quick interactions (like 'T' for ThemeToggle and 'K', 'I', 'L', 'O' for PathCard links). While the javascript captures the key events, the interactive HTML elements were missing `aria-keyshortcuts` which informs screen readers about the shortcut, as well as a visual hint in the `title` attribute for sighted users.
**Action:** When creating or encountering elements with custom keyboard shortcuts bound via javascript, ensure to add `aria-keyshortcuts="<key>"` to the interactive element, and append the shortcut hint (e.g. `(T)`) to its `title` or `aria-label` where applicable, making the feature accessible to both screen reader users and sighted users.
