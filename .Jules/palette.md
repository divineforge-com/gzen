## 2024-05-23 - Keyboard Shortcuts Discoverability
**Learning:** Interactive elements with custom keyboard shortcuts (like the Theme Toggle or Path Cards) should include `aria-keyshortcuts` for accessibility and `title="... (Shortcut: [Key])"` for visual discoverability by sighted users.
**Action:** Add both `aria-keyshortcuts` and an updated `title` to elements with custom keyboard shortcuts.
