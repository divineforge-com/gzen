## 2025-03-02 - Missing aria-keyshortcuts on Interactive Cards
**Learning:** The Astro portal uses keyboard shortcuts ('Z', 'E', 'N') to teleport to element cards (Water, Earth, Fire), but the interactive `<a>` elements for these cards lack the `aria-keyshortcuts` attribute and don't append shortcut info to their `title`. This makes these custom shortcuts undiscoverable to screen readers and sighted users hovering over the cards.
**Action:** When working on interactive elements with defined keyboard shortcuts (as explicitly mentioned in memory: "Interactive elements with custom keyboard shortcuts... must include the aria-keyshortcuts attribute... Append (Shortcut: [Key]) to the title attribute"), always add `aria-keyshortcuts="{key}"` and `title="... (Shortcut: {key})"` to improve accessibility and discoverability.
