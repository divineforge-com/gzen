Focus timer

A Pomodoro that breathes with you. Pick a length, close the other tabs, and let the bar fill.

go install github.com/divineforge/focus@latest

Go 1.22 or later · macOS, Linux, Windows · Source on GitHub · MIT

VHS demo GIF
focus.gif · 16:10

How to use it

Run focus for a 25-minute session, or pass a length.

focus 50m --break 10m

Keys

  • space pause or resume
  • s skip to break
  • q quit quietly
